# Contributing

1. Read `SECURITY.md` before working with wallets or deployment configuration.
2. Keep plaintext payroll amounts out of logs, URLs, events and persisted browser storage.
3. Add tests for every contract behavior change.
4. Run `npm run check` and the Docker-backed `npm test` before proposing a public release.
5. Explain any change to the privacy or TEE trust model in the README.

Bug reports should include reproducible steps without wallet secrets or real payroll data.
